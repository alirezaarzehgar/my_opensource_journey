\section{هفته چهارم}
\subsection{دوشنبه ۷ مهر}
از اخرین روزی که نشستم پای مشارکت تو گولنگ ۶ ماه و ۱۹ روز گذشته و این واقعا وحشتناکه برام :))
خیلی چیزا عوض شده تو این روز ها. تقریبا هرچیزی که فکرش رو کنید عوض شده. حتی عجیب شده!
رسما یک جنگ بین ایران و اسرائیل اتفاق افتاد و تموم شد. الان درگیر تحریم های جدید و اخبار عجیبیم. دلار شده ۱۱۳ تومن.
از maintainer های گولنگ، Ian Lance Taylor و Russ Cox که هردو تو ذهنم هستن و بهم جواب میدادن از گوگل رفتن.
من بعد از اخرین بارهایی که سعی کردم مشارکت کنم یه سری مصاحبه رفتم و جایی که میخواستم، که اسنپ بود ریجکتم کرد و نتونستم با عنوان مهندس نرم افزار کارمو
ادامه بدم.
راهبر مشهدلاگ شدم و چندین جلسه رو برگزار کردم.
الان تقریبا ۵ ماهه که تو شرکت پارت بعنوان دواپس دارم کار میکنم! که خب یکم درد داره ولی دردش کمه.
حتی آرچ لینوکس سیستمم رو پاک کردم و الان با NixOS دارم کار میکنم!

بگذریم از چیزایی که تغییر کرده، امروز بعد از مدت زیادی بالاخره به فکر مشارکتم افتادم. شاید عجیب باشه ولی همون کامیت آخر هنوز مرج نشده. الان ۱:۴۶ دقیقه صبحه، حالم میزون نیست،
فردا ۷ صبح باید بیدار بشم برم دانشگاه (نمیرم یحتمل)، سر کار هم باید برم و مطالعه روزانم رو هم انجام ندادم.
بهرحال باید یه روزی و یه ساعتی این CL پیگیری بشه.
راستش مشوق و دلیل اینکه یاد اینجا و این کار افتادم کتاب \lr{Software Engineering at Google} هست! تو اخرین فصلی که ازش خوندم از Gerrit هم گفت.
و خب باز کمر بستم تایم بذارم. حداقل این مشارکت اخری رو مرج کنم بعد بیخیال بشم.

فعلا امشب روی نیکس سورس کد گولنگ رو کلون کردم، رفتم از اوایل همین دفترچه خاطرات یه کمک گرفتم و gerrit رو درست کانفیگ کردم تا بتونم با \lr{git-codereview} کار کنم.

حالا هم یه چیز شگفت انگیز دیدم. میتونی patch و کلا CL ای که داشتی رو به روش های مختلف دانلود کنی روی سیستم و کدبیس جدید. کافیه سمت پایین توی CL روی دانلود کلیک کنید تا
منو بیاد. من این گزینه رو انتخاب کردم تا برنچ جدید باز کنه برام. ولی خب کلا جالب بود:

\begin{latin}
\begin{minted}[breaklines]{bash}
git fetch https://go.googlesource.com/go refs/changes/15/655115/5 && git checkout -b change-655115 FETCH_HEAD
\end{minted}
\end{latin}

حالا که تغییرات رو هم دانلود کردیم و کانفیگ درسته بریم ببینیم خانم محترم چی کامنت گذاشتن.

\begin{latin}
Sean Liao

I think this should test with multiple newlines
\end{latin}


خب حق داره. هرچند Ian قبلا تایید داده ولی ایشون خودش راهنمای خوبی بودن از قبلا هم. الانم به گردن ما حق دارن حالا یه تست اضافه که ایرادی نداره.
خب یک مشکل! باید اول toolchain گولنگ رو روی نیکس کامپایل کنم برای خودم بعد با همون ورژن تست بگیرم سورس‌کد رو من که دارم بدون \lr{shell.nix} کامپایل میکنم و مشکلی هم قرار نیست داشته باشم احتمالا.
فقط سر مسیر و فایل اجراییش باید ببینم میشه چه کرد. یکم نیکس متفاوته.

امروز کلا کار خاصی نکردم. چند تا تماس جواب دادم، هماهنگی های مشهدلاگ رو انجام دادم، سر کارم رو رفتم، همین کارایی که توضیح دادم رو انجام دادم و خیلی ریز باز سمت مشارکت دارم میام.
و خبر بد که کتاب نخوندم! امروز کلا سازنده نبودم. ایشالله فردا درست میشه. یه اولویت که زمانبر هم واقعا نیست همین مشارکت هست و اگر شد مشارکت های بیشتر.


الان که کامپایل شد گولنگ، برای اینکه اخرین ورژن رو استفاده کنیم برای توسعه، یه سری راه زیبا داریم تو نیکس. یکیش این هست که PATH رو دست کاری کنیم.
بعد خیلی راحت زندگیمون رو بکنیم.

\begin{latin}
\begin{minted}[breaklines]{bash}
PATH="$(pwd)/bin:$PATH"
\end{minted}
\end{latin}

یه راه هم اینه که واقعا رو خود سیستم نصب کنیمش. برای اون کار باید پکیج درست کرد. کلا \lr{Immutable infrastructure} داشتن چیز خیلی باحالیه
و بنظرم اصلا نباید ازش درسید. باید باهاش به شدت عشق کرد. و فعلا از سلوشن مسیر استفاده میکنم چون به نظرم به اندازه کافی منصفانه هست.

حالا که تستش رو اجرا کردم یه چیز جدید کشف کردم. خب سلوشنی که داشتیم فقط تا یک newline رو حذف میکردم و مشکلمون رو حل میکرد. خانم محترم میخوان که تو چند تا خط جدید هم بررسی بشه.
خب جواب سادست. اگر هیچ خط جدیدی نداشته باشیم کامنت هم نداشته باشیم، تو خروجی مثال هم نداریم. اگر بین کامنت اخر و کد ها کلا خط جدید نباشه بازم همه چیز درسته.
با تغییرات ما اگر بین اخرین کامنت و کد های قبلش یک خط جدید باشه، اون یکی که معمولا هم یکی هست حذف میشه و کامنت هم که مال نمایش خروجی هست و میره دیگه.
اما اگر بیشتر از اون یکی خط جدید اضافه بشه، به انتهای خروجی اضافه میشه.

چیزی که به ذهن من میرسه این هست که براش این عملکرد رو توضیح بدم و بگم اینطور کار میکنه. واقعا تست بیشتر لازم داره؟
من که بعید میدونم. الان ۲:۴۲ صبح هست. سعی میکنم بخوابم تا بتونم فردا حداقل یک کلاس رو شرکت کنم دانشگاه.

فکر کردم و دیدم همین لحظه دلم میخوام یکم کارش رو ببرم جلو و حداقل یه کامنت بذارم. من این کامنت رو براش گذاشتم و خوابیدم. به امید فردا:

\begin{latin}
\textbf{Sean Liao}:

I think this should test with multiple newlines

\textbf{Alireza Arzehgar}:

The behavior of this CL is to fix the number of newlines between the last code block and the output comment to exactly one. Currently, having more than one newline between the last code block and the output comment results in redundant (though perhaps deliberate) newlines at the end of the code example.

Should this CL remove all extra newlines, or do we just need more tests?

Thank you for your time and consideration.
\end{latin}
