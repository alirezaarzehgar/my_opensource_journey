# My Open Source Journey

This diary is about my journey of contributing to the Go programming language. Its name is generic because
at first I decided to talk about all of my contributions. Now I believe someone may want to see
just the Golang contributions. I will write more diaries about open source contributions because I believe
the hardest part of contributing is finding a way to start, finding a problem, accepting that it's
not impossible, and building enough self-confidence to do it.

This story was written in Persian using LaTeX. I'm translating it into English using AI because I don't have time to
rewrite it entirely.
Each week doesn't mean a continuous week. I just count each day and group every 7 days as a week :) It's weird, but
I think it's fun because you can decide and estimate for yourself how many days you will be involved in
similar activities. I don't care about gaps because the result is what matters to me, regardless of time.

Feel free to contribute to this diary by improving the LaTeX structure.
